# Pyodide Code Execution

## Project Overview

`pyodide-code-execution` is an **Open WebUI** tool that can execute Python code in the client browser using **Pyodide** and return the execution results.

## Usage

Download the `plugin.py` file from the [Releases page](https://github.com/EntropyYue/pyodide-code-execution/releases) and paste its contents into `/workspace/tools/create`.
